## 시작하기 (7회)

1. 이 저장소 오른쪽 위 **Use this template → Create a new repository**
   - 저장소 이름: 영어 소문자, 숫자, `-`만 (예: `grade-suika`)
   - **Public** 선택
2. 내 저장소에서 **Settings → Pages → Branch: `main`, `/ (root)` → Save**
   - 1분쯤 뒤 같은 화면 위쪽에 내 주소가 뜹니다: `https://아이디.github.io/저장소이름/`
3. VS Code에서 내 저장소를 열고(Clone), Claude에게 이렇게 시작합니다.
   > README.md와 CLAUDE.md를 읽고, 처음 시작할 때 할 일부터 해 줘.

## 카톡 미리보기가 예전 것으로 나올 때

카톡은 한 번 가져간 미리보기를 한동안 저장해 둡니다. 썸네일이나 제목을 바꿨는데 그대로라면:

1. [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에 접속 (카카오 계정 로그인)
2. 내 주소를 넣고 **캐시 초기화**
3. 카톡에 링크를 새로 보내서 확인
